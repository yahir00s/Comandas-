# Referencia del Menú Extraído

Esta documentación describe todos los items extraídos de las fotos del menú físico.

## Notas de Extracción

Las fotos del menú fueron proporcionadas por el cliente. Toda la información se extrajo cuidadosamente y se validó contra las imágenes originales.

### Items con Precios Variables

Los siguientes items tienen "precio según existencia" y requieren entrada manual:
- Vampiro (en Coctelería) - se agregó versión con precio fijo y variable
- Destilados: Todas y Mezcales

### Items con Variantes (Vaso/Litro)

Muchas bebidas tienen opciones de presentación:
- Mojitos (Litro)
- Perón Margarita (Litro)
- Bebidas sin alcohol (Copa/Vaso y Litro)
- Vinos (Copa y Botella)

### Extras Disponibles

**Para Pizzas:**
- Vegetal: $15
- Queso: $35
- Proteína: $35

**Para Pastas y Ensaladas:**
- Pollo: $55
- Camarones: $60
- Albóndigas: $55

## Verificación

Para verificar precios o items, consulta:
1. Las fotos originales del menú (si están disponibles)
2. El archivo `src/data/menu.js` con todos los datos estructurados
3. Confirma con el restaurante cualquier cambio o actualización
